# Facebook-Sentiment-Analysis
The project focuses on the social media text data to analyze user sentiment.
Understanding user sentiment on scoial media is essential for bussiness and decision making.
Project focuses on the facebook text data to classify user sentiment into Positive, Negative, Neutral using NLP Techniques.

**Features**
- Analyze social media text to determine user sentiment.
- Performs complex text cleaning & preprocessing.
- Converts textual data into numeric feature.
- Applies Machine Learning model for sentiment analysis.
- Improves performace through model tunning and evaluation.
  

**How it Works**
1. Collect and load facebook text data.
2. Perfrom text preprocessing-
    - tokenization
    - Stopword removal
    - Stemming/Lemmatization
3. Convert text into numeric features using TF-IDF.\
4. Train Machine Learning Model.
5. Predict sentiment- Positive,Negative,Neutral
6. Evalute model Performance and optimize.


**Learning**
-Learned Text Preprocessing and cleaning technique.
-Improved feature extraction using TF-IDF.
-Built understanding in NLP workflows and sentiment analysis.
-Understood impact of features in model evaluation.
